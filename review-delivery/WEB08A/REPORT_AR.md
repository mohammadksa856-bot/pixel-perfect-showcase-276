## 2. معيار جودة يصلح للبحث

نفصل أربع طبقات، دون تحويلها إلى درجة مخترعة:

1. **وجود وتوصيل:** هل الحقل في المصدر/الملف الخام/نموذج العرض/الواجهة؟ ليست هذه الحالات مترادفة.
2. **أهلية تقنية:** رقم وفترة ووحدة وعملة ونطاق ومصدر متسقة؛ تعارضات أو مشتقات بلا اعتماد تُحجب.
3. **أهلية بحثية:** تعريف اقتصادي واضح، تاريخ كافٍ، مقارنات قابلة للتفسير، إصدار المصدر وإعادة عرضه محفوظان.
4. **تحقق واعتماد:** دليل أصلي وبصمته والصفحة، تحقق مستقل للأرقام الحرجة وعينة طبقية تتوسع عند الخطأ، مراجعة تحريرية للنص، وحقوق العرض.

الأرقام المقبولة في العرض المجمد تبقى للاستكشاف، وليست تلقائيًا مدخلات تقييم معتمدة. النص المستخرج والمصادر الآمنة لا يثبتان صحة معنى الرقم. بقاء الحجب نجاح أمان، لا اكتمال للموضوع.

## 5. ما يمكن اشتقاقه وما لا يمكن الآن

`SOURCES-AND-DERIVATIONS.json` يوثق تسع وصفات **للمراجعة فقط**، مع المدخلات والفشل المتوقع. لا نتائج حسابية أُنتجت.

- CFO وcapex قد يسمحان بـFCF بعد حسم النقد/الإضافات/الاستثمار الرأسمالي وتعريف الإشارة والنطاق؛ وجودهما لا يفك حجب المشتق الحالي.
- هوامش وربح إلى نقد ونمو تحتاج فترات ومقامات متجانسة ومدخلات مؤهلة وإعادة إنتاج عبر lineage.
- ROE/ROA/ROIC تحتاج متوسطات وأساس أرباح/ضريبة ورأس مال؛ ROACE المعلن يبقى باسمه.
- Q4=FY−YTD9m للبنود التدفقية القابلة للجمع فقط؛ لا يُطرح EPS أو رصيد ميزانية أو نسبة. Q1/Q2 الحاليان لا يوفران YTD9m.
- CAGR يحتاج عدد الفواصل الفعلي وسياسة للقيم السالبة؛ TTM يحتاج أرباعًا كاملة أو فترة سنوية وتراكميين متناظرين.
- عائد توزيع/مضاعفات يحتاج السعر والعدد والتوزيعات والتعديلات بتاريخ قياس متسق، وحقوق مصدر؛ EPS الحالي غير مؤهل.
- beta والسيولة والعائد النسبي تحتاج تاريخ أسعار ومؤشر وإجراءات؛ المقارنة القطاعية تحتاج universe وتعريفًا متجانسًا.
- لا اشتقاق يملأ فئة مفقودة تلقائيًا، ولا يُنفذ في React. المشتق يحمل معرفاته ومدخلاته وإصداراتها ومعادلته وحالته «محسوب».

المدخلات التي تحتاج مصادر/حقوق جديدة: أسعار/حجم/مؤشر وتعديلات، تقديرات وتوصيات، أخبار ونصوص مكالمات، مجموعات بيانات قطاعية وأقران. وجود [فئات خدمات ورسوم لدى تداول](https://www.saudiexchange.sa/wps/portal/saudiexchange/rules-guidance/fees?locale=en) لا يثبت امتلاكنا الرخصة ولا يقرر نطاقها؛ المطلوب مراجعة عقد الخدمة المختارة دون شراء تلقائي.

- تقرير منهجيات ROIC/FCF/EV/TTM ومدخلاتها؛ لا بناء DCF حتى إجازة المدخلات والمنهجية منفصلًا.

## 11. أدلة التسليم وحدوده

- `DISPLAY-INVENTORY.json`: كل صف/فترة/وحدة وحكم مصدر يستهلكه النموذج، دون تصدير الأرقام الخام أو المستندات. مراجع SRC توسع عبر `source_registry`.
- `RAW-ROUTING-INVENTORY.json`: مفاتيح مخزنة وأقسام خام وقدرات/أسباب، لا حق اعتماد مالي.
- `COVERAGE-MATRIX.json`: الموضوعات والمتطلبات والفجوات والمعايير المقترحة، لا درجات.
- `SOURCES-AND-DERIVATIONS.json`: المصادر المرشحة وحالة الوصول/الحقوق وتسع وصفات مشروطة، لا حسابات منفذة.
- `BROWSER-OBSERVATION.json`: جرد DOM فعلي لكل موضوع؛ أعداد الروابط/الجداول هي عقد DOM تشمل نسخ الجوال/الكمبيوتر المطوية، وليست أدلة فريدة.
- `audit-snapshot.ts` و`audit.test.ts`: جرد واختبارات سلامة هذا التسليم فقط. ليست إصلاحات تطبيق أو اختبارات تحقق مالي مستقل.

لا ادعاء بإعادة كل اختبارات WEB-07 أو تنزيل كل المصادر أو فحص المحرك الحي أو اختبار API حي. فحص المتصفح الحالي يؤكد ما يظهر في مرجع المعاينة المعتمد؛ ليس تدقيقًا جديدًا لكامل المنتج. لم تتغير منهجية 95% أو ملفات المنتج المقبولة.
