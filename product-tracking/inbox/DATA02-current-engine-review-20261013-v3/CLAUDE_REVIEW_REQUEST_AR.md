## استكمال مالي محلي — حزمة v2

أضاف المصنع الحالي خمس خلايا مالية ناقصة بعد مراجعة9خلايا أصلية بصريًا: أكوا باور (other_reserves،share_capital،other_expense)، دله وجرير (finance_costs السنوية). جميعها بوحدةSAR بعد التطبيع، مع حفظ الإشارة والنص الأصلي للعنوان في extraction.location.source_label، وبصمةPDF الأصلية. لا كود معادلة جديد ولا تعريف مقياس جديد.

هذه5إضافات تقنية محلية فقط، وليست قبولًا ماليًا أوإذن عرض إنتاجي. تواريخ الإفصاح الرسمية غير مثبتة، والمصدر يصرّح `official_known_at=null` و`accepted_for_display=false`. ردود API المالية للحزمة v2 تخص قاعدة معاينة جزئية: تاريخ الشركات الخمس الأولى مع الإضافات الجديدة للشركات التالية؛ لا تمثل كامل صفوف السوق. اختيار الخلايا الناقصة طابق مصفوفةALLSA المحفوظة، ولم تُعد92هوية موجودة.
