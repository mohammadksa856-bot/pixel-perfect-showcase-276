## R02-F: المقام الصفري بدقة

### السبب الجذري
- **Python** (`tools/recipes.py`، عند `18e0e8a` السطر 561):
  - فحص الإشارة `den <= 0` يعمل على قيمة double.
  - مقام صفري بدقة، مثل `0.1 + 0.2 − 0 + (−0.3)`، قيمته double تساوي `5.55e-17 > 0`، فيمرّ الفحص.
  - ثم ينفّذ `xs[0] / xs[1]` قسمة `Fraction` على صفر، فيرمي `ZeroDivisionError`.
- **TypeScript:** يحدث الشيء نفسه.
  - `qDiv` تبني مقامًا صفريًا دون أن ترمي.
  - ثم يرمي `roundHE` استثناء `RangeError` في قسمة BigInt.

### الإصلاح

**الملف `tools/recipes.py`:**
- الأسطر 574–577: تُفحص إشارة المقام بقيمته الدقيقة **قبل أي قسمة**.
  - المقام الدقيق ≤ 0: `denominator_not_positive`، وهو الكود الحالي في العقد.
  - المقام الدقيق > 0 مع double ≤ 0: `precision_not_guaranteed:<output>`.
- الأسطر 335–337: المقسوم عليه الدقيق داخل التعبير (`/ 2` و`/ policy_gas_scf_per_boe`).
