# W0 — ملخص المراجعة الأمنية المنقّح

**الحالة الهندسية: REWORK.** هذا ملخص عام، وليس تصريحًا بتشغيل W0 أو اعتمادها أو نشر الموقع.

| الأولوية | الملاحظة والأثر | الإجراء المطلوب | حالة الإصلاح |
|---|---|---|---|
| P1 | حدود صلاحية الوصول إلى معلومات المراجعة الخاصة غير كافية. | فرض صلاحيات فعلية على الخادم وفصل معلومات المراجع عن بيانات العرض العام. | مفتوح؛ ينتظر الإصلاح وإعادة الاختبار المستقل. |
| P2 | هوية ربط الدليل لا تتحقق من جميع الأبعاد المالية اللازمة، مما قد يؤدي إلى إسناد غير صحيح. | استكمال فحص الهوية والتعارض، والرفض الآمن عند الاختلاف. | مفتوح؛ ينتظر الإصلاح وإعادة الاختبار المستقل. |
| P2 | اختبارات الحزمة الأصلية لا تُعاد بصورة صحيحة على Windows. | معالجة قابلية نقل الاختبارات وإعادة تشغيل النسخة الأصلية دون تخفيف التأكيدات. | مفتوح؛ ينتظر الإصلاح وإعادة الاختبار المستقل. |

هذا الملخص لا يتضمن صورًا أو حمولات أو خطوات إعادة إنتاج أو إعدادات وصول. تبقى الأدلة التفصيلية خاصة. لا يمنح نشره قبولًا هندسيًا أو ماليًا أو حقوقيًا أو إذن دمج أو تشغيل أو نشر إنتاجي.
